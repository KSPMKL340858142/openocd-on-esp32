Wi-Fi 省电模式
开（省电）：空闲省电降温，但串口小包转发可能延迟至 ~400ms，示波器波形会卡。
关（RF 常开）：延迟稳定（实测 p95 62ms），代价空闲多耗 ~60-80mA、模组温热。
示波器/调试时建议关闭。切换立即生效并记忆，无需重启。
调试参数
JTAG/SWD 引脚（esp_gpio）
接目标芯片的 SWD/JTAG 连线。
不可用：19-20(USB)、26-37(Flash/PSRAM)、43-44(控制台)。
保存后自动重启。
文件与配置
OpenOCD 的 target 配置文件（.cfg，如 ti_mspm0.cfg）： 芯片 SRAM 地址、Flash 算法、复位方式。不是调试参数。
上传后要回「调试参数」卡片选中它才生效。
全部运行配置合成一个 JSON：Wi-Fi、调试参数、引脚、RTT 轮询、串口桥。 在电脑上改好传回来即可。
导入后自动重启并应用。
