Wi-Fi 省电模式
开（省电）：空闲省电降温，但串口小包转发可能延迟至 ~400ms，示波器波形会卡。
关（RF 常开）：延迟稳定（实测 p95 62ms），代价空闲多耗 ~60-80mA、模组温热。
示波器/调试时建议关闭。切换立即生效并记忆，无需重启。




JTAG/SWD 引脚配置（esp_gpio）
本机作为调试器，通过这些 GPIO 与目标芯片的 JTAG/SWD 相连。
保留脚不可用：19/20(USB)、26-37(Flash/PSRAM)、43/44(控制台)。
保存后设备自动重启并应用新引脚。
